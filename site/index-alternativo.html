Como aparecer aqui

Adicionar seu nome nesta página é a sua primeira contribuição real num projeto de código aberto — e é exatamente o conteúdo dos encontros 09 e 10 do módulo 2, aplicado de verdade.

# 1. faça um fork deste repositório no GitHub, depois:
git clone https://github.com/SEU-USUARIO/JT.git
cd JT

# 2. crie a sua branch
git switch -c aluno/seu-nome

# 3. abra o index.html e copie um bloco <div class="al">,
#    trocando o nome, as iniciais e os links pelos seus

# 4. salve o seu trabalho
git add index.html
git commit -m "feat: adiciona SEU NOME à turma"
git push -u origin aluno/seu-nome

# 5. no GitHub, abra um Pull Request. Eu reviso e faço o merge.
Travou em algum passo? Ótimo — é para travar mesmo na primeira vez. Traz o erro para a aula que a gente resolve junto, ou abre uma issue no repositório descrevendo o que aconteceu. Abrir issue também é conteúdo do módulo.
